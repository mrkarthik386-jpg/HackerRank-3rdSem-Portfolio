## Problem Descriptions

### 1. Diagonal Difference

This problem involves calculating the sum of the primary and secondary diagonals of a square matrix and finding the absolute difference between the two sums.

**Complexity:**

* Time: O(N)
* Space: O(1)

### 2. Dynamic Array

This problem focuses on dynamic sequences and query processing. It uses sequence selection based on XOR operations and maintains the required answers.

**Complexity:**

* Time: O(N + Q)
* Space: O(N)

### 3. Time Conversion

This problem converts a 12-hour AM/PM time format into the 24-hour format.

**Complexity:**

* Time: O(1)
* Space: O(1)

### 4. Compare the Triplets

This problem compares the corresponding scores of two participants and calculates the score obtained by each participant.

**Complexity:**

* Time: O(1)
* Space: O(1)

### 5. Sparse Arrays

This problem counts the number of occurrences of each query string in a given collection of strings.

**Complexity:**

* Target Time: O(N + Q)
* Target Space: O(N)
